# Sorties numériques historiques

Ces fichiers sont les sorties des scripts, utilisées par le harnais pour vérifier les valeurs
publiées. La version Institut actuelle utilise les surcharges dans
[sorties_verif_inst](../sorties_verif_inst/), dont le manifeste atteste les exécutions.

Le harnais compare le texte aux sorties ; il ne relance pas les simulations. Les données brutes
restent hors du dépôt. Les identités des entités SFCR et les valeurs vraies d'élicitation sont
masquées dans la version publique.
